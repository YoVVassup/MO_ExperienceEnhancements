# Feature Showcase — Miscellaneous Changes & Fuzzy Orders (Smart Middle-Click Series)
This document introduces the plugin's features in more detail and with pictures.
This part covers miscellaneous changes and fuzzy orders (the smart middle-click series).

![alt text](imgs/img_esc_kjj.png)

## Miscellaneous operations
### Select only mind-controlled units
shift + p unit filter: select only mind-controlled units.
Conflicts a bit with the native shift, not very convenient...
Can be bound to another hotkey, e.g. a mouse side button works fine.
![alt text](imgs/oth_psx.png)

### Simplified attack-move, custom hotkey
Simplified attack-move with a custom hotkey allowed.
Currently defaults to a mouse side button; change it as needed.

### Ignore unsupported orders, avoid suicidal sends
When left-click attacking, repair units have no attack ability but will still move to the target
location, which often sends such units to the front line to die.
Supports filtering repair units out of the left-click attack command so they don't run to their death.
The middle-click fuzzy order series supports this too.

### Simple aggressive mode
Use alt + a to put units into aggressive mode; useful for auto-attacking harmless structures.
Can also be configured to auto-attack other units, solving the lazy-navy problem.
The range is the larger of the guard range and the weapon range.
For online compatibility it only takes effect while units are idle.
A small icon distinguishes the state.
![alt text](imgs/other_alta.png)

## Fuzzy operations (smart middle-click series)
The keys mentioned below are hotkeys in the config file.
All hotkeys are customizable.

### Middle-click move
Air units scatter to their positions instead of all using the same target point.
On the left, after several moves the target points merge and units bunch up; on the right, waypoints are
assigned per unit.
![alt text](imgs/img_zjyd.jpg)

#### Ground units cluster
Uses a spiral arrangement, convenient for Iron Curtain and the like.
In the picture: normal move on the left, middle-click move on the right.
![alt text](imgs/img_zjxljj.png)

### Middle-click line move
Quick and simple formations, evenly distributed along the drawn line.
![alt text](imgs/img_zjhx.gif)

### Middle-click + Z combo — patrol circle
z + middle-click automatically creates a small patrol circle; can pin aircraft or repair aircraft so
they don't wander off.
Drag to draw a line — quickly create a straight patrol circle.
Drag a closed line — create a patrol circle that follows the path.
![alt text](imgs/img_zjgn.gif)

### Deploy preview and auto-deploy
MCV-type units get a deploy preview placeholder and can auto-move into position and deploy.
Drag a single unit with the middle mouse button to reposition it.
For multiple units:
Consideration is given to avoiding overlap after moving.
Draw a line to assign positions and deploy automatically; shift forces a straight line.
See the fragments in the picture:
1 auto-avoid overlap. 2 even distribution. 3 supports irregular previews. 4 avoids already deployed
units in advance.
![alt text](imgs/oth_zkylzb.gif)

### Middle-click combo — quick tree clearing
ctrl + z + middle-click.
Hold to preview the logging area.
Affects trees, street lamps and other terrain clutter within the range; you don't need to click on a
tree.
![alt text](imgs/img_zjfm.gif)

### Fuzzy orders
The middle-click's purpose is moving; this one is for picking targets.
I don't want too much automation, so no fire distribution and no automatic "best choice".
Implemented:
Quick assignment and garrisoning of buildings.
Engineers repairing own buildings in bulk.
Adaptive capturing of empty vehicles.
Assigning power plants (EP) and tank bunkers.
Assigning target enemies in groups of 4.

![alt text](imgs/img_zdxz.gif)

### Fuzzy attack orders
Quick selection of an attack target.
ctrl+middle-click, aimed at hard-to-select units like Terror Drones.
See the mid-demo in the image; hold ctrl+middle-click to auto-snap.
![alt text](imgs/img_dzgd.gif)
(The niche is mostly taken by shift+middle-click now; it wasn't planned to be that strong...)
