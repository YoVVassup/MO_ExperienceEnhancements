# Документация по функциям — разное и нечёткие приказы (серия «умной» средней кнопки)
Этот документ подробнее и наглядно знакомит с функциями плагина.
Здесь — разные функции и нечёткие приказы (серия умной средней кнопки).

![alt text](imgs/img_esc_kjj.png)

## Разные операции
### Выделять только управляемые телепатом юниты
shift + p фильтр юнитов: выделяет только управляемые телепатом.
Слегка конфликтует с нативным shift, не очень удобно...
Можно переназначить на другую клавишу, например боковую кнопку мыши — и всё работает.
![alt text](imgs/oth_psx.png)

### Упрощённый attack-move, настраиваемая горячая клавиша
Упрощённый attack-move с возможностью задать свою горячую клавишу.
По умолчанию сейчас боковая кнопка мыши; меняйте под себя.

### Игнорировать неподдерживаемые приказы, чтобы не посылать на самоубийство
При атаке левой кнопкой ремонтные юниты не умеют атаковать, но идут к точке цели — из-за этого такие
юниты часто уходят на фронт и погибают.
Поддерживается фильтрация ремонтных юнитов из команды атакы левой кнопкой, чтобы они не бежали на
смерть.
Серия нечётких приказов средней кнопкой это тоже поддерживает.

### Простой режим агрессии
alt + a переводит юниты в режим агрессии; годится для автоатаки безвредных построек.
Можно настроить и на автоатаку других юнитов — решает проблему ленивого флота.
Диапазон — большее из двух: охранная зона и радиус оружия.
Ради совместимости в онлайне срабатывает только, пока юниты стоят на месте.
Состояние отличается маленькой иконкой.
![alt text](imgs/other_alta.png)

## Нечёткие операции (серия умной средней кнопки)
Клавиши ниже — горячие клавиши из файла конфигурации.
Все настраиваются.

### Движение по средней кнопке
Авиация разлетается по своим точкам вместо того, чтобы идти на одну общую цель.
Слева после нескольких перемещений точки цели сливаются и юниты сбиваются в кучу; справа маршрутные
точки назначаются по юнитам.
![alt text](imgs/img_zjyd.jpg)

#### Сборка наземных юнитов
Используется спиральное расположение — удобно для Силового поля и подобных.
На картинке: слева обычное движение, справа — средней кнопкой.
![alt text](imgs/img_zjxljj.png)

### Движение по линии средней кнопкой
Быстрые простые построения, равномерно распределённые по проведённой линии.
![alt text](imgs/img_zjhx.gif)

### Комбинация средняя кнопка + Z — патрульный круг
z + щелчок средней кнопкой автоматически создаёт маленький патрульный круг; можно закрепить самолёт
или ремонтный вертолёт, чтобы не разбегались.
Проведите линию — быстро создадите прямой патрульный круг.
Проведите замкнутую линию — получите патрульный круг, следующий по пути.
![alt text](imgs/img_zjgn.gif)

### Превью развёртывания и авто-развёртывание
Для юнитов типа МCV появляется превью-плейсхолдер развёртывания, они могут сами занять место и
развернуться.
Перетащите одного юнита средней кнопкой, чтобы переставить.
Для нескольких юнитов:
Учитывается обход наложений после перемещения.
Проведите линию — позиции назначатся и развёртывание произойдёт автоматически; shift принудительно
прямая.
См. фрагменты на картинке:
1 автоматический обход наложений. 2 равномерное распределение. 3 поддержка неправильных превью.
4 заблаговременный обход уже развёрнутых юнитов.
![alt text](imgs/oth_zkylzb.gif)

### Комбинация средней кнопки — быстрая рубка деревьев
ctrl + z + средняя кнопка.
Удерживайте, чтобы увидеть область рубки.
Действует на деревья, фонари и прочий рельеф в радиусе; кликать прямо по дереву не нужно.
![alt text](imgs/img_zjfm.gif)

### Нечёткие приказы
Средняя кнопка — про движение, это — про выбор цели.
Слишком много автоматики мне не нужно, поэтому распределения огня и «авто-лучшего выбора» нет.
Реализовано:
Быстрое распределение и заселение в здания.
Массовый ремонт своих зданий инженерами.
Адаптивный захват пустой техники.
Распределение ЭС-станций и танковых бункеров.
Распределение врагов группами по 4.

![alt text](imgs/img_zdxz.gif)

### Нечёткие приказы на атаку
Быстрый выбор цели атаки.
ctrl+щелчок средней кнопкой — для плохо выделяемых юнитов вроде Террор Дронов.
См. середину демо на картинке; удерживайте ctrl+среднюю — будет автопривязка.
![alt text](imgs/img_dzgd.gif)
