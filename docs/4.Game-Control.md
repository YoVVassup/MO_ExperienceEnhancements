# Feature Showcase — Game Control
![alt text](imgs/img_esc_gmkc.png)

### Game speed control
Finer-grained game speed control, in steps of 5 frames; the speed cap raised from 60 to 120, above 120
there is no limit.
Custom frame rates can be typed in.
The counting method differs, so it does not match the in-game FPS display.
```
FixEngineFps=0	; fix the counted frame rate; the counting method differs, enable to align the display
```
### Range display
Shows some unit ranges.
Firing range, minimum range, anti-air range, stealth detection, spy detection, deploy weapon range.
To avoid UI clutter, hold ctrl to show them for a single unit.

### Crate type icons
Campaign crate type display was added; has no effect on random crates in skirmish.

### Turn off mind-control loss notices
Solves the problem of too many mind-controlled units being lost and the notices being annoying.
When enabled, loss notices for units acquired via mind control are filtered out.
![alt text](imgs/gif_xkss.gif)

### Aircraft waypoints
Aircraft can use waypoints.
But for online play it stops there, because attack-move doesn't work and it would desync.
Fixing it would cause desyncs, and faking a pseudo-waypoint system is a hassle.
Right-click micro and the like still work for forced attacks.

You can use a patrol circle to tether an aircraft to a spot; after reloading it flies back to the
circle automatically.
Works together with the middle-click features. (The picture uses the quick patrol-circle creation.)
![alt text](imgs/img_dzgd.gif)

### Local cheering
With units selected, press C to make them cheer; handy for screenshots and video recording...
With nothing selected it is still map-wide cheering; disabled online.

### Communication beacon adjustments
Placing a beacon online automatically deletes the old one.
In single player you can place beacons; the limit of 3 is lifted, up to 24.
Can be used to show arrow directions...
Not very useful yet, but future-proof (e.g. AI advisors).

### Lift the 128 move/waypoint limit
The cap is lifted in single player; online it uses per-frame order dispatch,
implemented by issuing orders in batches — for safety it is disabled online by default, but can be
enabled.
```
[Features]
OrderThrottle=1	; issue orders to large armies per frame, lifting the 128 limit (0=disabled, same as vanilla; 1=single player only; 2=online as well)
```
Lifts the single-player waypoint limit of 16 and the 128 total-unit waypoint limit.
Waypoints sync online, so it cannot be enabled there.
![alt text](imgs/other_pathpoint.png)

### Lift the 500-selection box limit
Lifts the limit where you can't box-select beyond 500 displayed units, and adds a query interface.
500 is a hard limit; lifting it would be incompatible with other extensions that need to read the
selected units.
Note:
Automatically disabled in a Phobos environment.
Auto-loading got a query capability for the 500 limit; the old ctrl+T type filter might crash, or
definitely crashes past 500 — the new one doesn't.

### Fix spectator logic
Single-player spectating now shows the spectator panel.
Online, with several spectators, other observers can also show the spectator panel.
Fixed spectating breaking after loading a save, and the game ending when any AI is defeated.
![alt text](imgs/img_obs2.png) ![alt text](imgs/img_obs.png)

### Fix map problems at high resolutions
When the view is larger than the map, the map used to jitter back and forth; it is now centered,
fixing the high-resolution display problem.
Edge jaggies are filled with smooth straight lines.
This is best-effort; at similar resolutions some jaggies may still appear.
![alt text](imgs/img_fix.jpg)
