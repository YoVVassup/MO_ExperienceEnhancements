# New GUI features
## Buildings
### Building queue
A building construction queue, implemented by simulating player actions.
Not stored in save games; using it online introduces a slight delay.
This is because the standard queue is synced in multiplayer with no delay, while simulated player
actions have one.

![alt text](imgs/img_ui_bq_txt.png)

### Scatter units while placing
Comes as automatic and manual scattering.
If you place buildings with a hotkey, automatic scattering is for you.
If you don't want units scattered by accident, use manual scattering.
```
[PlaceScatter]
Mode=1		; 0=disabled (vanilla behavior), 1=scatter on click (default, nudges shadows without touching units), 2=shadow follows and auto-scatters
Interval=30	; Mode=2 rescan interval (logic frames, 5~300, default 30)
Batch=16	; max move events emitted per trigger (1~64, default 16)
Dist=2		; cells pushed outward after leaving the box (1~4, default 2)
```

![alt text](imgs/img_qzdyb2.gif)

### Building placement and deploy preview
Shows a ghost preview in building-placement mode; opacity is configurable, works for deployable units
and in zoom mode.
```
[PlacementPreview]
Opacity=25
```

![alt text](imgs/img_gui_zkyl.png)

### Polyline waypoints for production buildings
Factories can set complex rally points with Z. Useful for avoiding threats.
Essentially waypoint-based, so somewhat of a niche feature.
Conflicts a bit with player actions, since waypoint submission is global — while the player is in
waypoint mode, units wait.

![alt text](imgs/other_bpath.png)

### Simplified building repair
What's enabled by default is quick repair, not auto repair.
Ctrl+repair or double-click repair.
Either via hotkey or the UI button.
Auto repair is also supported.
The extension includes a repair filter so things that shouldn't be repaired aren't.

## Superweapon sidebar list
Customizable sorting: put your favorite superweapons first.
By default the Force Shield and Iron Curtain come first; sorting uses superweapon names and priorities.
Collapsible, takes no space; superweapons on the Defense Support page can be hidden for a clean defense
page.
By default one column per faction (Allied/Soviet/Escaron/Burning each get a column); right-click the
show/hide arrow to switch to "fill mode": sorting ignores factions, columns are kept roughly equal in
height — two columns first, then three/four as needed, scrolling only starts at four columns, reducing
page flipping.
You can configure the number of **rows** shown, or show it on the **left** if there are too many
superweapons.
```
[SWSidebar] ; configuration reference, elided.
ToggleKey=F4		; toggle show/hide. Hidden means neither drawn nor taking space. Syntax see Hotkey.md
Alpha=75			; sidebar opacity 0~100. Applies to most of what the sidebar draws
DedupDefensePage=1	; dedupe the vanilla "Defense Support" page. 1 = superweapons already shown in the sidebar no longer repeat on the vanilla page
MaxRows=10			; max entries per column. Excess is hidden, a scrollbar appears on the right
FillMode=0			; display mode: 0=columns per faction (default) 1=fill mode. Right-click the show/hide arrow to switch live
TopMargin=180		; vertical position, ratio 0 ~ 1, 0.5 = vertically centered, 0.25 = higher up. Greater than 1 = pixels
ScrollStep=1		; rows moved per scroll wheel tick
Side=right			; panel dock side: right/left. Allies always hug the screen edge, Escaron always the map interior
FillMode=0			; display mode: 0=columns per faction (default) 1=fill mode (ignores factions, columns kept roughly equal in height)

; ---- superweapon priority ----
; negative = hide that superweapon;  0 or omitted = show by default (priority 1000)
; positive = priority, smaller number = earlier. Full list see SuperweaponList.md
ForceShieldSpecial=1
IronCurtainSpecial=1
```

## Bottom bar and sidebar features

![alt text](imgs/img_bot_btn.png)

### Map zoom
Zoom in or widen the view with the bottom bar zoom buttons.
You can remove the MAX level limit for a true full map, though the frame rate may be low.
```
[BottomBar]
LimitFallback=8192	; long-edge pixel cap (default 8192). 0 = no limit; non-zero below 3820 is treated as 3820; over the cap is clamped
```

![alt text](imgs/img_sca.png)

### Pause
Pause with F5; single player only.
Pause and frame-step buttons then appear on the bottom bar.
Pause any time with F5 and the bottom bar.
You can issue orders while paused, but rendering waits for the next frame.

![alt text](imgs/img_dzgd.gif)

### Grid display
The grid button shows up alongside F5.
The grid is not an exact feature: red unreachable areas and obstacles are not detected correctly.
Cliff detection is unreliable, but it can display transparent overlays that block building or movement.

![alt text](imgs/img_show_gr.png)

### UI-less screenshot
The camera button left of the bottom bar zoom scale (hidden by default; enable it on the GUI page of
the ESC menu).
Good for campaign screenshots, replaces the holographic screenshotter.
The screenshot contains no UI, is written into Screenshots as PNG.

![alt text](imgs/img_fullmap.png)


## Sidebar features
### Draggable scrollbar in the sidebar
Makes long sidebar lists easy to scroll — see the blue bar on the right of the image.
Not shown when the list isn't long enough.
If it's in the way but you still need the scrollbar, you can set its width to hide it.
```
[Sidebar]
HitWidth=14			; scrollbar active width (pixels, 6~20): click/drag hit area
ShowWidth=6			; scrollbar visible width, slider draw width
```

![alt text](imgs/img_ui_swp.png)

### Hide the sidebar
Handy for squad missions or cutscenes.
Toggles between fully shown, minimap only, and fully hidden.

![alt text](imgs/img_ui_cl_yccl.gif)

### Show build time and power usage
Shows build time and power drain on buildings/units in the build list.

## Unit info panel
### View basic info

![alt text](imgs/img_ui_up.png)

Shows ammo, veterancy, self-heal, ore and other info.
Shows a vehicle's passengers; supports picking one unit type out of a multi-type selection.
Right-click kicks the selected member or member group out.

Supports **unloading specific passengers**, but disabled online.

Supports using waypoints for members inside a vehicle, with multi-select.
Shift-click to select passengers one by one, or click the vehicle icon to select all passengers.

### Unit panel sidebar
Some features can be turned off or on.
Supports collapsing the panel, or persistently showing veterancy info.
Supports a WASD mode toggle, useful for solo-infantry missions — a niche toy...

Supports favoriting units and showing arrows; can also mark communication beacon positions.
First click favorites, second click jumps, or ctrl+click to favorite,
shift adds multiple favorites, long-press clears favorites.

You can set arrows to show at the center or at the screen edge.
Useful for sidebar-hidden infantry campaigns and for finding teammate beacons...

![alt text](imgs/img_uiupcbl.png)

## Small window
Opened from a sidebar button.
Click the minimap in the small window to jump there, or right-click to move the view.
Click the alert icon to auto-jump to the most recent event, same as the space bar jump.

Can watch AI or issue remote orders:
Enable the mouse icon to operate remotely inside the small window — e.g. for Iron Curtain strikes,
two-front micro without switching screens.

Follow units:
With focus on the small window, press F to follow without focus, including enemies. Same as F-follow,
except it also works with the selection cleared.

# UI text rendering improvements & bug fixes
Improves in-game UI and text rendering, fixes some UI bugs.

## Message list improvements (campaign text centered)
The in-game message queue was rewritten to vector rendering; fonts are configurable, important and
secondary information are displayed separately.
Campaign briefing text was redrawn for better display.
Default config shows it centered at the bottom; you can change it back to the top-left.
It appears after the mouse rests on the trigger area for a moment; a quick pass shows nothing.
```
CampBottom=0		; 1=show at the bottom (bottom edge fixed, text grows upward), 0=show at the top
CampBottomMargin=150;pixels from the bottom edge in bottom mode
CampCentered=0		; 1=horizontally centered, 0=left-aligned (PosX)
PosX=2				; top-left margin
PosY=2
TopGapLines=0		; reserved lines at the top
MaxWidth=0.75		; box width: integer=pixels, 0=auto (half screen); 0~1 fraction=percentage of screen width (e.g. 0.5); cap=screen width-170
```
Fig 1: top-left mode still available.
Fig 2: typewriter style still supported, obeys the basic disappearance rules, can be set to appear
instantly.
Fig 3: hovering the mouse scrolls through history text.

## IME fixes and enhancements
Lets players use the chat box in single player; text shows in the important-messages area, so you can
[pretend to talk to the campaign text](#fake-dialog)
Supports copy, paste, cursor movement and other basics.
Font and position are configurable.
Up/down arrow keys cycle through input history.
Fixed the bug where the IME was stuck in the top-left corner; the IME now follows the input box.

![ime](imgs/img_ime.png)

You can set frequently used texts and recall them quickly in game.

![ime](imgs/img_ime_pre.png)


## Orders and battle hints
Unimportant information — a.k.a. battle info — is split off; ordering absent units no longer covers
the campaign text.
Configurable separately; if you prefer the player color, you can switch it back. (Not all options
listed.)
```
HintFontFace=simsun.ttc	; hint box font
HintColorFollow=0	; 0=white text, 1=follow the player's actual color (vanilla color)
HintMaxLines=6		; number of lines shown
HintMaxWidth=400	; box width in pixels, 0=auto
```

### Power indicator
Bottom power indicator for a clearer view of remaining power.
Can be centered at the bottom or next to the power number; two styles available.
The config uses the left style; switch to the right style as follows.
```
PowerX=0			; 0=centered on the sidebar (default); >0=absolute x inside the sidebar area
PowerPad=0			; distance from the screen bottom to the bar, pixels
PowerMode=0			; 0=load/power (default); 1=margin as a plain number (positive=OK, negative=short)
```
