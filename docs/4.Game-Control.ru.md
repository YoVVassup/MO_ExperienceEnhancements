# Документация по функциям — управление игрой

![alt text](imgs/img_esc_gmkc.png)

### Управление скоростью игры
Более тонкое управление скоростью игры с шагом 5 кадров; потолок скорости поднят с 60 до 120, выше
120 — без ограничения.
Своё значение частоты можно ввести вручную.
Способ подсчёта другой, поэтому с отображением FPS в игре не совпадает.
```
FixEngineFps=0	; починить подсчёт кадров (способ подсчёта другой), включить — выровнять отображение
```
### Отображение радиусов
Показывает некоторые радиусы юнитов.
Дальность стрельбы, минимальная дальность, дальность ПВО, обнаружение стелса, обнаружение шпионов,
радиус оружия при развёртывании.
Чтобы не засорять интерфейс, удерживайте ctrl — покажет для одного юнита.

### Маршрутные точки самолётов
Самолёты могут использовать маршрутные точки.
Но в онлайне на этом всё: attack-move не работает и вызывает рассинхрон.
Починить — значит вызвать рассинхрон, а эмулировать псевдо-маршрутные точки слишком заморочено.
Правый клик и микро по-прежнему позволяют принудительно атаковать.

Можно закрепить самолёт патрульным кругом; после перезарядки он сам летит обратно в круг.
Работает в связке со средней кнопкой. (На картинке — быстрое создание патрульного круга.)

![alt text](imgs/img_dzgd.gif)

### Локальный восторг
С выделенными юнитами нажмите C, чтобы они порадовались; удобно для скриншотов и видеозаписей...
Если ничего не выделено — восторг по-прежнему по всей карте; в онлайне отключено.

### Настройки связи-маяка
При установке маяка в онлайне старый автоматически удаляется.
В одиночной игре ставить можно; ограничение 3 снято, ставить до 24.
Можно показывать стрелки-наводки...
Пока в целом не особо полезно, но на будущее (например, ИИ-советник).

### Снятие лимита 128 на перемещения и маршрутные точки
В одиночной игре лимит снят; в онлайне приказы раздаются по кадрам,
реализовано пакетной выдачей — для надёжности по умолчанию в онлайне отключено, но включить можно.
```
[Features]
OrderThrottle=1	; раздача приказов большим армиям по кадрам, снимает лимит 128 (0=выключено, как в ваниль; 1=только одиночная игра; 2=и в онлайне)
```
Снят одиночный лимит 16 маршрутных точек и общий лимит 128 юнитов на маршрутные точки.
Маршрутные точки в онлайне синхронизируются, поэтому включить там нельзя.

![alt text](imgs/other_pathpoint.png)

### Снятие лимита рамки выделения в 500
Снят лимит, из-за которого после 500 отображаемых юнитов рамкой было нельзя выделять, добавлен
интерфейс запроса.
500 — жёсткий лимит; его снятие несовместимо с другими расширениями, которым нужен список выделенных.
Внимание:
В окружении Phobos отключается автоматически.
В авто-погрузку добавлена возможность запроса лимита 500; старый фильтр ctrl+T мог падать, а про 500
падал точно — новый нет.

### Исправлены проблемы карты при высоком разрешении
Когда обзор больше карты, карта дёргалась туда-сюда; теперь она центрируется, и проблема высокого
разрешения решена.
Зубчатость краёв заливается плавными прямыми.
Это максимум возможного; при близких разрешениях зубчатость может остаться.
