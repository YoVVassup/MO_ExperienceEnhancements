# Новые функции интерфейса
## Здания
### Очередь строительства
Очередь постройки зданий, реализованная имитацией действий игрока.
В сохранения не попадает; в онлайне даёт небольшую задержку.
Стандартная очередь в онлайне синхронизируется без задержки, а имитация действий игрока задержку даёт.
![alt text](imgs/img_ui_bq_txt.png)

### Рассеивание юнитов при установке
Бывает автоматическое и ручное.
Если ставите здания горячей клавишей — берите автоматическое.
Если не хотите, чтобы юнитов разбрасывали случайно, — ручное.
```
[PlaceScatter]
Mode=1		; 0=выключено (поведение ванили), 1=рассеивать по клику (по умолчанию, отодвигает тени, не трогая юнитов), 2=следящая тень с авто-рассеиванием
Interval=30	; интервал повторного скана для Mode=2 (кадры логики, 5~300, по умолчанию 30)
Batch=16	; максимум событий движения за одно срабатывание (1~64, по умолчанию 16)
Dist=2		; на сколько ячеек отодвигать за пределами рамки (1~4, по умолчанию 2)
```
![alt text](imgs/img_qzdyb2.gif)

### Превью установки и развёртывания зданий
В режиме установки здания показывается призрачное превью; прозрачность настраивается, работает для
юнитов с развёртыванием и в режиме масштабирования.
```
[PlacementPreview]
Opacity=25
```
![alt text](imgs/img_gui_zkyl.png)

### Ломаные маршрутные точки для производственных зданий
Заводы могут задавать сложные точки сбора клавишей Z. Полезно для обхода угроз.
По сути это обычные маршрутные точки, так что функция нишевая.
Слегка конфликтует с действиями игрока: отправка маршрута глобальная, пока игрок в режиме маршрутных
точек, юниты ждут.
![alt text](imgs/other_bpath.png)

### Упрощённый ремонт зданий
По умолчанию включён быстрый ремонт, а не авто-ремонт.
Ctrl+ремонт или двойной клик по ремонту.
Через горячую клавишу или кнопку интерфейса.
Авто-ремонт тоже поддерживается.
В расширении есть фильтр ремонта: то, что чинить не надо, не чинится.

## Список супероружий на боковой панели
Настраиваемая сортировка: любимые супероружия — вперёд.
По умолчанию впереди Силовое поле и Железный занавес; сортировка использует названия и приоритеты.
Сворачивается и не занимает места; супероружия страницы «Оборонительная поддержка» можно скрыть для
аккуратной страницы обороны.
По умолчанию по колонке на фракцию (союзники/советские/эскарон/пекловоды); правый клик по стрелке
показа/скрытия переключает в «режим заполнения»: фракции игнорируются, колонки уравниваются по
высоте — сначала две, при нехватке три/четыре, прокрутка начинается только с четырёх колонок, так
меньше перелистываний.
Можно настроить число отображаемых **строк** либо при слишком большом списке показывать его **слева**.
```
[SWSidebar] ; справка по конфигурации, местами сокращено.
ToggleKey=F4		; показать/скрыть. В скрытом виде не рисуется и места не занимает. Синтаксис см. Hotkey.md
Alpha=75			; прозрачность панели 0~100. Действует на большую часть того, что панель рисует
DedupDefensePage=1	; дедупликация ванильной страницы «Оборонительная поддержка». 1 = супероружия, уже показанные на панели, не дублируются на ванильной странице
MaxRows=10			; максимум записей в колонке. Остальные не показываются, справа появляется полоса прокрутки
FillMode=0			; режим отображения: 0=колонки по фракциям (по умолчанию) 1=заполнение. Правый клик по стрелке показа/скрытия переключает на лету
TopMargin=180		; вертикальная позиция, доля 0 ~ 1, 0.5 = по центру, 0.25 = выше. Больше 1 = пиксели
ScrollStep=1		; сколько строк за один щелчок колеса
Side=right			; сторона крепления панели: right/left. Союзники всегда у края экрана, эскарон — у внутреннего края карты
FillMode=0			; режим отображения: 0=колонки по фракциям (по умолчанию) 1=заполнение (фракции игнорируются, колонки уравниваются по высоте)

; ---- приоритет супероружий ----
; отрицательное = скрыть супероружие;  0 или не указано = показывать по умолчанию (приоритет 1000)
; положительное = приоритет, меньше = раньше. Полный список см. 超武列表.md
ForceShieldSpecial=1
IronCurtainSpecial=1
```

## Функции нижней панели и боковой панели
![alt text](imgs/img_bot_btn.png)
### Масштаб карты
Увеличение отображения или расширение обзора кнопками масштаба на нижней панели.
Можно снять ограничение уровня MAX для настоящей полной карты, но частота кадров будет невысокой.
```
[BottomBar]
LimitFallback=8192	; потолок пикселей по длинной стороне (по умолчанию 8192). 0 = без ограничения; ненулевое меньше 3820 считается 3820; сверх потолка — обрезается
```
![alt text](imgs/img_sca.png)

### Пауза
Пауза по F5; только в одиночной игре.
Затем на нижней панели появляются кнопки паузы и покадрового шага.
Пауза в любой момент через F5 и нижнюю панель.
Во время паузы приказы отдавать можно, но отрисовка ждёт следующий кадр.
![alt text](imgs/img_dzgd.gif)

### Отображение сетки
Кнопка сетки появляется вместе с F5.
Сетка — не точная функция: недоступные красные зоны и препятствия определяются неправильно.
Определение утёсов ненадёжно, но прозрачные накладки, блокирующие строительство или движение,
показывать можно.
![alt text](imgs/img_show_gr.png)

### Скриншот без интерфейса
Кнопка фотоаппарата слева от шкалы масштаба нижней панели (скрыта по умолчанию; включается на
странице GUI в меню ESC).
Удобно для скриншотов кампании, заменяет голографический скриншотовер.
На скриншоте нет интерфейса, файл кладётся в Screenshots в формате PNG.
![alt text](imgs/img_fullmap.png)


## Функции боковой панели
### Перетаскиваемая полоса прокрутки в панели
Удобно прокручивать длинные списки — см. синюю полосу справа на картинке.
Не показывается, если список недостаточно длинный.
Если мешает на глаза, но прокрутка нужна, можно задать ширину и скрыть.
```
[Sidebar]
HitWidth=14			; рабочая ширина полосы (пиксели, 6~20): зона клика/перетаскивания
ShowWidth=6			; видимая ширина полосы, ширина отрисовки ползунка
```

## Маленькое окно
Открывается кнопкой на боковой панели.
Клик по миникарте в маленьком окне переносит туда, правый клик двигает обзор.
Клик по иконке тревоги — авто-прыжок к последнему событию, как пробел.

Можно наблюдать за ИИ или отдавать приказы издалека:
Включите иконку мыши, чтобы управлять удалённо внутри окна — например, ударами Железного занавеса,
микро на двух фронтах без переключения экранов.

Следование за юнитами:
Когда фокус на маленьком окне, нажмите F — будет следование без фокуса, включая врагов. То же, что
F-следование, но работает и когда выделение снято.

# Улучшения отрисовки текста интерфейса и исправления багов
Улучшает отрисовку текста и интерфейса в игре, чинит некоторые баги интерфейса.

## Улучшения списка сообщений (центрированный текст кампании)
Очередь сообщений в игре переписана на векторную отрисовку; шрифт настраивается, важная и второстепенная
информация выводятся раздельно.
Текст брифинга кампании отрисован заново для лучшего показа.
По умолчанию показывается по центру внизу; можно вернуть в левый верхний угол.
Появляется, когда мышь некоторое время покоится на области триггера; быстрого прохода мало.
```
CampBottom=0		; 1=показ внизу (нижний край фиксирован, текст растёт вверх), 0=показ сверху
CampBottomMargin=150;пиксели от нижнего края в нижнем режиме
CampCentered=0		; 1=по центру по горизонтали, 0=по левому краю (PosX)
PosX=2				; отступ от левого верхнего угла
PosY=2
TopGapLines=0		; зарезервированные строки сверху
MaxWidth=0.75		; ширина рамки: целое=пиксели, 0=авто (полэкрана); дробь 0~1=доля ширины экрана (напр. 0.5); потолок=ширина экрана-170
```
Рис. 1: режим левого верхнего угла по-прежнему доступен.
Рис. 2: машинописный стиль по-прежнему поддерживается, соблюдает базовые правила исчезновения, можно
настроить на мгновенное появление.
Рис. 3: наведение мыши прокручивает историю текста.

## Исправления и улучшения метода ввода (IME)
Позволяет использовать чат-бокс в одиночной игре; текст выводится в области важных сообщений, так что
можно [притвориться, что беседуешь с текстом кампании](#fake-dialog)
Поддерживается копирование, вставка, перемещение курсора и прочие базовые операции.
Шрифт и позиция настраиваются.
Стрелки вверх/вниз листают историю ввода.
Исправлен баг, из-за которого IME был приклеен в левый верхний угол; теперь IME следует за боксом
ввода.
![ime](imgs/img_ime.png)
Можно задать часто используемые тексты и быстро вызывать их в игре.

## Подсказки приказов и боя
Неважная информация — она же боевая — вынесена отдельно; приказы отсутствующим юнитам больше не
перекрывают текст кампании.
Настраивается отдельно; если нравится цвет игрока, можно вернуть. (Перечислены не все опции.)
```
HintFontFace=simsun.ttc	; шрифт рамки подсказок
HintColorFollow=0	; 0=белый текст, 1=следовать реальному цвету игрока (цвет ванили)
HintMaxLines=6		; сколько строк показывать
HintMaxWidth=400	; ширина рамки в пикселях, 0=авто
```

### Индикатор энергии
Индикатор энергии внизу для наглядного остатка питания.
Может быть по центру внизу или рядом с числом энергии; доступны два стиля.
В конфигурации используется левый стиль; переключиться на правый так:
```
PowerX=0			; 0=по центру на боковой панели (по умолчанию); >0=абсолютный x в области панели
PowerPad=0			; расстояние от нижнего края экрана до полосы, пиксели
PowerMode=0			; 0=нагрузка/энергия (по умолчанию); 1=запас обычным числом (плюс=хватает, минус=не хватает)
```
