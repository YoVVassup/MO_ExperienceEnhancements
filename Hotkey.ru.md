# Синтаксис горячих клавиш (Hotkey)

Применяется к: пунктам `Hotkey` в `[PatrolCircle]`, `[SmartOrder]`, `[TreeChop]` и
`[FuzzyAttack]` файла `MOExperience.ini`, пунктам `MindSelect`/`AttackMove` в `[Features]`,
пунктам `ToggleKey` в `[SWSidebar]` и `[Sidebar]`, а также пункту
`PauseHotkey` в `[BottomBar]`.

## Правила

- Формат: модификатор(ы) + клавиша, связанные `+` или пробелом. Пример: `Shift+P`, `Ctrl+Z+Middle`.
- Регистр не важен: `ctrl+z` = `Ctrl+Z`.
- Пробелы/Tab в любом месте игнорируются: `  ctrl + z  ` = `Ctrl+Z`.
- Всё после `;` в конце строки — комментарий, отрезается: `Hotkey=Middle ; рассеивание` оставляет только `Middle`.
- При нескольких клавишах **последняя — основная, предыдущие нужно удерживать**:
  `Ctrl+Z+Middle` = удерживать Ctrl и Z, затем нажать среднюю кнопку мыши.
- `None` / `Off` / `Disabled` — функция выключена.
- Отсутствующая клавиша, пустая строка или опечатка → используется значение по умолчанию; ничего не ломается.
- Однострочные переключатели (`MindSelect`/`AttackMove` в `[Features]`): `0` = выкл.,
  записанная клавиша = вкл. с ней, отсутствие пункта = вкл. с клавишей по умолчанию.

## Модификаторы

| Запись | Значение |
|---|---|
| `Ctrl` (`Control`) | Клавиша Ctrl |
| `Shift` | Клавиша Shift |
| `Alt` (`Menu`) | Клавиша Alt |
| `Win` (`Windows`) | Клавиша Win |

## Клавиши

Отдельные буквы/цифры пишутся напрямую: `A`~`Z` (буквы), `0`~`9` (цифры), `F1`~`F24`.

Внимание: многозначные числа интерпретируются как старые значения `TriggerVK`, например `80`=P,
`90`=Z, `4`=средняя кнопка мыши; одиночный `4` — это цифра 4. Для средней кнопки пишите `Middle`.

### Функциональные клавиши

| Запись | Клавиша |
|---|---|
| `Space` | Пробел |
| `Tab` | Tab |
| `Enter` (`Return`) | Enter |
| `Backspace` (`Back`) | Backspace |
| `Insert` (`Ins`) | Insert |
| `Delete` (`Del`) | Delete |
| `Home` | Home |
| `End` | End |
| `PageUp` (`PgUp`) | PageUp |
| `PageDown` (`PgDn`) | PageDown |
| `Up` / `Down` / `Left` / `Right` | Стрелки |
| `Pause` | Pause |
| `Num0`~`Num9` | Цифровой блок 0~9 |

### Мышь

| Запись | Кнопка |
|---|---|
| `Middle` (`MMB`) | Средняя кнопка мыши |
| `LMB` | Левая кнопка мыши |
| `RMB` | Правая кнопка мыши |
| `X1` | Боковая кнопка 1 (вперёд) |
| `X2` | Боковая кнопка 2 (назад) |

## Значения по умолчанию

| Функция | `Hotkey` по умолчанию | Описание |
|---|---|---|
| Патрульный круг `[PatrolCircle]` | `Z+Middle` | Удерживайте Z и ведите средней кнопкой — рисуете круг; уступает претензии «умного радиуса» |
| Умный приказ `[SmartOrder]` | `Middle` | Простой клик средней адаптируется (движение/атака/вход/заселение), протяжка — рассеивание; удержание Z уступает патрулю, Ctrl — нечёткому, комбинации со средней — зонно-адаптивному |
| Валка деревьев `[TreeChop]` | `Ctrl+Z+Middle` | Все три клавиши одновременно |
| Нечёткая атака `[FuzzyAttack]` | `Ctrl+Middle` | Уступает патрулю/валке, пока зажат Z; Ctrl+Shift+средняя тоже считается нечёткой; во время удержания красная линия планирования ведёт к назначенной цели и исчезает при отпускании |
| Атака с движением `[Features]` (`AttackMove`, однострочный) | `X2` | Оригинальная атака с движением с Ctrl+Shift+левой кнопкой (Mission=29); одиночная клавиша (напр. `X2`/`A`) стреляет прямо по наведённой клетке, комбинация с левой кнопкой (напр. `A+LMB`) отдаётся по левому клику; удержание Z — очередь (waypoints); комбинации с левой кнопкой дополнительно делают одно оригинальное выделение — если мешает, используйте одиночную клавишу |
| Умный радиус `[SmartArea]` | `Shift+Middle` (основной — `Middle`; можно заменить на одиночную клавишу вроде `X1`) | Клик/протяжка по блокам (каждый узел траектории) выбирает цели; при удержании тонкая зелёная линия ведёт к каждой назначенной цели (исчезает при отпускании), каждый объект получает приказ по правилу своего курсора (без перемещения); запрос курсора использует встроенный курсор юнита (ignoreForce=1), физический Shift/Ctrl не портит проверку; без приказа действует таблица правил: чужие транспорт/авиация/пехота (не здания) → силовая атака, инженеры против зданий/пустого транспорта → захват (с лимитом 1 по цели), пехота против своего транспорта → посадка, остальные свои пропускаются, пехота без инженера против зданий → ожидание; отпускание — выполнить; «ожидание» пересматривается после отпускания всех «грязных» клавиш; с зажатым Ctrl считается нечётким, Z не блокируется |
| Фильтр телепатии `[Features]` (`MindSelect`, однострочный) | `Shift+P` | В конце остаются только управляемые телепатией юниты |
| Панель супероружия `[SWSidebar]` | `F4` (`ToggleKey`) | Показать/скрыть правую панель супероружия (скрытая не занимает места) |
| Скрыть панель `[Sidebar]` | `F11` (`ToggleKey`) | Трёхсостоянный цикл оригинальной панели: полная / только миникарта и кнопки / на весь экран |
| Пауза в одиночной игре `[BottomBar]` | `F5` (`PauseHotkey`) | Пауза/продолжить (только skirmish/кампания, в сети не работает; `PauseEnable=0` отключает полностью); левый клик по нижней панели: отдельные кнопки паузы/продолжения и покадрового шага (появляются после первого нажатия F5, дальше всегда видны) |
